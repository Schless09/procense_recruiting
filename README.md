# procense_recruiting

Recruiting tooling for Procense (Ashby, Aimfox, Notion), run with Claude Code.

## Setup
1. `cp .env.example .env` and fill in the Procense keys.
2. Fill in the TODOs in `CLAUDE.md` so Claude has the company and role context.
3. Put any candidate exports or resumes in `data/` (never committed).
